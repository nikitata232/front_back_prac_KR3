О приложении

Версия: 1.3.0

Приложение «Заметки» с поддержкой уведомлений в реальном времени.

Возможности

  • Добавление и просмотр заметок
  • Синхронизация между вкладками через WebSocket
  • Push-уведомления при добавлении новых задач
  • Офлайн-режим через Service Worker
  • Устанавливается как PWA

Технологии

  • Node.js + Express
  • Socket.IO (WebSocket)
  • Web Push API + VAPID
  • Service Worker + Cache API
  • Web App Manifest
