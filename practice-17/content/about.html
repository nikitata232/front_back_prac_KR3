О приложении

Версия: 1.4.0

Приложение «Заметки» с поддержкой напоминаний и отложенных push-уведомлений.

Возможности

  • Добавление заметок без напоминания
  • Добавление заметок с датой и временем напоминания
  • Push-уведомление в назначенное время (даже при закрытом приложении)
  • Кнопка «Отложить на 5 минут» прямо в уведомлении
  • Синхронизация между вкладками через WebSocket
  • Офлайн-режим через Service Worker

Технологии

  • Node.js + Express
  • Socket.IO (WebSocket)
  • Web Push API + VAPID
  • Service Worker Notification Actions
  • setTimeout для планирования уведомлений
