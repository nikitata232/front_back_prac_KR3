# Практика 17 — Детализация Push (напоминания + snooze)

## Что это

Расширение приложения из Практики 16: добавлены **напоминания с указанием даты/времени** и возможность **отложить уведомление на 5 минут** прямо из системного уведомления.

## Структура проекта

```
practice-17/
├── server.js               — Node.js сервер с планировщиком напоминаний
├── package.json
├── index.html              — App Shell
├── app.js                  — клиент: заметки с напоминаниями, WebSocket, push
├── sw.js                   — Service Worker: push + notificationclick (snooze)
├── manifest.json
├── icons/
├── content/
│   ├── home.html           — две формы: обычная заметка + заметка с напоминанием
│   └── about.html
└── README.md
```

## Что добавлено по сравнению с Практикой 16

### Форма напоминания (`content/home.html`)

Добавлена вторая форма `#reminder-form` с полями:
- `<input type="text">` — текст напоминания
- `<input type="datetime-local">` — дата и время срабатывания

### Структура заметок изменена

Каждая заметка теперь хранит объект:
```js
{ id: Date.now(), text: "...", reminder: 1748123456789 }  // reminder — timestamp или null
```

Заметки с напоминанием отображаются с зелёным бейджем с датой.

### Планирование напоминаний на сервере (`server.js`)

При получении события `newReminder` от клиента:
1. Вычисляется `delay = reminderTime - Date.now()`.
2. Создаётся `setTimeout` на вычисленную задержку.
3. По истечении таймера — push всем подписанным клиентам с `reminderId`.
4. Хранилище `reminders` (Map) хранит `{ timeoutId, text, reminderTime }`.

### Откладывание напоминания (`/snooze`)

Эндпоинт `POST /snooze?reminderId=<id>`:
1. Находит активное напоминание по id.
2. Отменяет текущий таймер (`clearTimeout`).
3. Создаёт новый таймер на 5 минут.
4. Обновляет запись в Map.

### Service Worker: действия уведомления (`sw.js`)

Для push-уведомлений с `reminderId` добавляются **кнопки действий**:

```js
options.actions = [
  { action: 'snooze', title: 'Отложить на 5 минут' },
  { action: 'dismiss', title: 'Закрыть' }
];
```

Обработчик `notificationclick`:
- `action === 'snooze'` → `fetch('/snooze?reminderId=...')` → напоминание переносится.
- `action === 'dismiss'` → уведомление закрывается.
- Клик на само уведомление → открывает/фокусирует вкладку приложения.

## Как запустить

```bash
npm install
npm start
```

Открыть: `http://localhost:3001`

## Как протестировать

1. Открыть приложение, нажать **«Включить уведомления»**.
2. Во вкладке «Главная» заполнить форму «Добавить с напоминанием»: ввести текст и выбрать время через 1–2 минуты.
3. Нажать **«+ Напоминание»** — заметка появится в списке с зелёным бейджем времени.
4. Свернуть браузер или переключиться на другое приложение.
5. В назначенное время придёт системное push-уведомление с кнопками.
6. Нажать **«Отложить на 5 минут»** — уведомление придёт повторно через 5 минут.
7. Нажать **«Закрыть»** — уведомление закрывается без повтора.
8. Кликнуть на само уведомление — браузер откроет/сфокусирует вкладку приложения.

> **Важно**: Напоминания хранятся в памяти сервера — при рестарте `node server.js` активные таймеры сбрасываются. Для production нужно персистентное хранилище (БД или файл).
