# Практика 18 — Подготовка к контрольной работе №3

## Что это

Итоговое занятие: тестирование, документирование и подготовка репозитория с результатами Практик 13–17.

Новый код в этой практике не пишется — задача состоит в том, чтобы убедиться в работоспособности всего реализованного, оформить документацию и сдать работу.

---

## Чеклист тестирования

### Практика 13 — Service Worker

**Запуск:**
```bash
cd practice-13
npx http-server -p 8080
```

- [ ] Страница открывается по `http://localhost:8080`
- [ ] Можно добавить заметку — она появляется в списке
- [ ] После перезагрузки страницы заметки сохраняются (localStorage)
- [ ] DevTools → Application → **Service Workers** — SW активен (статус `activated`)
- [ ] DevTools → Application → **Cache Storage** → `notes-cache-v1` содержит `index.html`, `app.js`
- [ ] DevTools → Network → включить **Offline**, обновить страницу — страница загружается из кэша
- [ ] При отключённой сети заметки по-прежнему добавляются и отображаются

### Практика 15 — App Shell + HTTPS

**Запуск:**
```bash
cd practice-15
npx http-server -p 8080
```

- [ ] При открытии страницы каркас (шапка + навигация) виден сразу
- [ ] Клик по «Главная» — загружается форма и список заметок
- [ ] Клик по «О приложении» — загружается страница `about.html`
- [ ] DevTools → Application → Cache Storage — присутствуют два кэша: `app-shell-v1` и `dynamic-content-v1`
- [ ] Режим **Offline**: перезагрузка страницы — всё работает из кэша
- [ ] Режим **Offline**: переключение между вкладками навигации работает

**HTTPS (опционально):**
```bash
brew install mkcert && mkcert -install
mkcert localhost 127.0.0.1 ::1
npx http-server --ssl --cert localhost.pem --key localhost-key.pem -p 3000
```
- [ ] В адресной строке отображается замок (Secure)
- [ ] DevTools → Security → статус «Secure»

### Практика 16 — WebSocket + Push

**Запуск:**
```bash
cd practice-16
npm install
npm start
```

- [ ] Сервер запустился: `Сервер запущен: http://localhost:3001`
- [ ] Страница открывается по `http://localhost:3001`
- [ ] Кнопка «Включить уведомления» запрашивает разрешение браузера
- [ ] После разрешения кнопка меняется на «Отключить уведомления»
- [ ] Добавление заметки в одной вкладке → в другой вкладке появляется синий toast
- [ ] При активной подписке добавление заметки → приходит системное push-уведомление
- [ ] Кнопка «Отключить уведомления» → push перестают приходить, toast продолжают работать
- [ ] DevTools → Application → Cache Storage — присутствуют кэши `app-shell-v2` / `dynamic-content-v2`

### Практика 17 — Напоминания + Snooze

**Запуск:**
```bash
cd practice-17
npm install
npm start
```

- [ ] Сервер запустился без ошибок
- [ ] Форма «Добавить с напоминанием» отображается на главной странице
- [ ] Поле `datetime-local` позволяет выбрать дату и время
- [ ] Нельзя установить напоминание в прошлом (выводится `alert`)
- [ ] После добавления заметки с напоминанием — в списке отображается зелёный бейдж с датой
- [ ] В назначенное время приходит системное push-уведомление
- [ ] В уведомлении отображаются кнопки «Отложить на 5 минут» и «Закрыть»
- [ ] Нажатие «Отложить на 5 минут» → уведомление закрывается и приходит повторно через 5 минут
- [ ] Нажатие «Закрыть» → уведомление закрывается без повтора
- [ ] Клик на само уведомление → открывает/фокусирует вкладку приложения
