### App Shell архитектура

**App Shell** — минимальный набор HTML/CSS/JS, который формирует каркас интерфейса и кэшируется при первом посещении. Контент подгружается динамически.

- `index.html` содержит только постоянные элементы: шапку (`<header>`) и навигацию (`<nav>`). Основной контент (`<main id="app-content">`) изначально пуст.
- При клике на кнопку навигации `app.js` делает `fetch('/content/page.html')` и вставляет результат в `#app-content`.
- При загрузке страницы «Главная» вызывается `initNotes()`, которая навешивает обработчики на форму.

### Две стратегии кэширования в SW

| Тип ресурса | Стратегия | Описание |
|---|---|---|
| Статика (`/`, `app.js`, иконки, манифест) | **Cache First** | Из кэша — мгновенно, при отсутствии идёт в сеть |
| Динамический контент (`/content/*.html`) | **Network First** | Сначала сеть (актуальный контент), при ошибке — из кэша |

Два отдельных кэша:
- `app-shell-v1` — статические ресурсы, заполняется при `install`
- `dynamic-content-v1` — страницы контента, заполняется динамически

## Настройка HTTPS с mkcert

Service Worker и PWA требуют HTTPS. Для локальной разработки используется `mkcert`:

```bash
# 1. Установить mkcert
brew install mkcert

# 2. Создать доверенный локальный CA
mkcert -install

# 3. Сгенерировать сертификат для localhost (выполнить в папке проекта)
mkcert localhost 127.0.0.1 ::1
# Создаст файлы: localhost.pem и localhost-key.pem

# 4. Запустить сервер с HTTPS
npx http-server --ssl --cert localhost.pem --key localhost-key.pem -p 3000
```

Открыть: `https://localhost:3000` — в адресной строке появится замочек.

> Без mkcert можно запустить через обычный HTTP на localhost — браузеры разрешают SW на `localhost` без HTTPS.

## Как запустить (без HTTPS)

```bash
npx http-server -p 8080
```

## Как проверить App Shell

1. Открыть DevTools → **Application** → **Cache Storage** — увидеть два кэша: `app-shell-v1` и `dynamic-content-v1`.
2. На вкладке **Network** включить **Slow 3G** — каркас (шапка + навигация) появляется сразу, контент подгружается чуть позже.
3. Включить **Offline** и обновить страницу — приложение полностью загружается из кэша.
4. Переключение между «Главная» и «О приложении» работает офлайн благодаря `dynamic-content-v1`.
