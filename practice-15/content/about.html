О приложении

Версия: 1.2.3

Приложение «Заметки» — простой менеджер задач и заметок, работающий в офлайн-режиме.

Возможности

  • Добавление и просмотр заметок
  • Сохранение данных в localStorage — без потери при перезагрузке
  • Офлайн-режим через Service Worker
  • Устанавливается как PWA на устройство
  • App Shell — мгновенная загрузка каркаса приложения

Технологии

  • Vanilla JS, HTML5, CSS
  • Service Worker (Cache API)
  • Web App Manifest
  • App Shell Architecture
